This project is a 2.5D top-down shooter prototype developed during my pre-college years as a way to explore game development fundamentals. The game uses 2D sprites placed in a 3D environment to achieve a 2.5D look. It features basic player movement, shooting mechanics, and a simple enemy AI that follows the player.

The prototype was built using Unity and scripted with C#, with additional help from Mathematica for calculating angles, distances, and certain movement formulas.
